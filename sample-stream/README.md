# sample-stream

Java 8 Streams (pur Java, sans Vertigo) sur des jeux de données CSV/texte.
Chaque exercice existe en version **exo** (services à implémenter) et **corrige** (complété).

| Sous-module | Type | Jeu de données |
|---|---|---|
| [01-sample-starbucks-exo](01-sample-starbucks-exo) | Exo | `starbucks.csv` — compter, filtrer par état, histogramme par ville, top-N |
| [01-sample-starbucks-corrige](01-sample-starbucks-corrige) | Corrigé | Idem |
| [02-sample-scrabble-exo](02-sample-scrabble-exo) | Exo | `maupassant.txt` — concaténation, fréquences, score scrabble |
| [02-sample-scrabble-corrige](02-sample-scrabble-corrige) | Corrigé | Idem |

Lancer la classe main de chaque sous-module (`io.vertigo.samples.main.MainStarbucks` / `MainScrabble`) ; les résultats attendus sont donnés dans chaque README de sous-module.
