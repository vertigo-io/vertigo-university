# 02-sample-twitter

Envoi d'un tweet via un client Twitter4J brut (sans node Vertigo).

## Démarrage

- **Prérequis** : créer `src/main/resources/twitter4j.properties` avec les identifiants OAuth (consumer key/secret, access token/secret) d'un compte
- Lancer la classe main `io.vertigo.twitter.TwitterSample` : poste le statut « Tweet ! »

## Contenu

- `twitter.TwitterSample` : la classe main (Twitter4J)
